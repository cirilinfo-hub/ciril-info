# Tooltip

Dark (`ink-900`, white 12/500) or light (white + `shadow-md`); radius 8, padding 8×12, max-width 220, 8px offset, `z-tooltip`. Opens on hover/focus after 300ms, closes immediately.

## Use
Never put interactive content in a tooltip. Wrap one focusable element.

## Props
`content`, `light`, `open` (force open), one child element.
