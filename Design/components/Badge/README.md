# Badge

24px pill, 12/700, padding-x 10, optional 6px dot. Semantic tones pair the `-50` background with `-700` text (all AA).

## Use
Status always carries a word, never colour alone. Green (`success`) is for positive change and completion only.

## Props
`tone` `'brand' | 'neutral' | 'success' | 'warning' | 'error' | 'info'`, `dot`, children.
