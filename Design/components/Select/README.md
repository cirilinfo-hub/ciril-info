# Select

Native select styled as the input pill with a chevron. Trigger follows the input spec.

## Use
- Prefer the native select for forms and mobile.
- A custom listbox (menu radius 16, padding 8, `shadow-lg`, `z-dropdown`; options 40px, radius 10, hover `ink-100`, selected `violet-50` + `violet-700` 600 with a check) is specified in the source but not built yet.

## Props
`label`, `hint`, `error`, `options` (strings or `{value,label,disabled}`), plus `<select>` attributes.
