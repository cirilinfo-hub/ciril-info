# FeatureCard

White card, radius 16, padding 24, 44px icon tile (radius 12). On white use a 1px `color-border-subtle` border **or** a shadow, never both. `onBrand` renders the violet-band version with a 16% white tile.

## Props
`icon` (Icon name), `title`, `onBrand`, children (description, `body-sm`).
